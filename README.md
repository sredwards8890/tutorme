# TutorMe

A two-person tutoring room (voice, shared whiteboard, Excel screen share, PNG snapshots)
for one tutor on an iPad with a stylus and one student on Windows. No accounts, no server,
no hosting bill.

- `app/` — the application. Deployed to https://sredwards8890.github.io/tutorme/
- `spike/` — Phase 0 device tests, kept at https://sredwards8890.github.io/tutorme/spike/
- `docs/PLAN.md` — design and phase plan
- `docs/SPIKE_RESULTS.md` — what was measured on the real devices

Each person joins from a private link minted with `npm run mint` in `app/`.
